# voice — 超音波データ通信 実機テスト

スピーカーから音を出し、相手のマイクで拾って、その音の中に埋め込んだデータを取り出します。
**電波もネットも使いません。**

👉 **https://224096-cmd.github.io/voice/**

## できること

- 文字列の送受信（長文は自動で分割して送信）
- 受信スペクトラムのリアルタイム表示、使用帯域のピーク dB 表示
- 周波数帯の可変と帯域スキャン
- タップ入力モールス / 電鍵
- ホーム画面に追加して単体アプリとして起動（PWA）

音声処理には [ggwave](https://github.com/ggerganov/ggwave) 0.4.3 を使っています。

## 使い方

1. 上のリンクを2台の端末で開く
2. 両方で「マイクを開始」を押す
3. 片方で文章を入れて「送信」。もう片方のログに出れば成功

音量は大きめに、端末同士は近づけて。反響の多い部屋のほうが届くこともあります。

## ホーム画面に追加

- **iPhone / iPad** … Safari で開き、共有ボタン → ホーム画面に追加
- **Android** … Chrome のメニュー → アプリをインストール

## ファイル構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | 本体。UI・DSP・ggwave 呼び出しまで全部入り |
| `sw.js` | 通知用のサービスワーカー。キャッシュはしない |
| `manifest.json` | PWA の設定（名前・アイコン・配色） |
| `icon-*.png` / `icon.svg` | ホーム画面・タスク切替用アイコン |
| `apple-touch-icon.png` | iOS のホーム画面用アイコン |
| `favicon.ico` / `favicon.svg` | ブラウザのタブと検索結果用 |
| `og-image.png` | SNS 共有カードの画像 |
| `sitemap.xml` | 検索エンジン向けサイトマップ |

## 注意

- マイクを使うため HTTPS 必須です（GitHub Pages ならそのまま満たします）
- 17 kHz を超える音は多くの人に聞こえませんが、鳴っています。ペットや子どもがいる場所、音量には配慮してください
- 端末のスピーカー／マイクの周波数特性しだいで届く距離は大きく変わります
